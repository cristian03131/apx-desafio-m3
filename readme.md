# Desafío M3 - Maquetado Responsive (APX)

Este es el tercer desafío del Nivel 2 de APX, donde el objetivo es recrear un diseño de Figma utilizando **HTML5 Semántico** y **CSS (Flexbox/Grid)** con un enfoque profesional y responsive.

## 🚀 Demo
Puedes ver el sitio funcionando aquí: 
👉 [https://cristian03131.github.io/apx-desafio-m3/]

## 🛠️ Tecnologías utilizadas
* **HTML5:** Arquitectura semántica (`header`, `main`, `section`).
* **CSS3:** Mobile First, Flexbox y CSS Grid.
* **Git & GitHub:** Control de versiones y despliegue.

## 📋 Lecciones Aprendidas
* Implementación de contenedores "Wrapper" para el control de anchos máximos.
* Uso de arquitectura modular inspirada en estándares de la industria.
* Configuración de despliegue automatizado con GitHub Pages.
