# Desafío M3 - Maquetado Responsive (APX)

Este es el tercer desafío de la carrera Full Stack Developer en **apx**, donde el objetivo principal fue recrear un diseño de Figma desde cero, aplicando buenas prácticas de maquetación, arquitectura de carpetas y adaptabilidad responsive.

## 🚀 Demo
Puedes ver el sitio funcionando en vivo aquí:  
👉[Ver Demo en GitHub Pages](https://cristian03131.github.io/apx-desafio-m3/)


## 🛠️ Tecnologías y Prácticas Utilizadas
* **HTML5 Semántico:** Estructuración limpia usando etiquetas como `<header>`, `<main>`, `<section>` y `<footer\>`.
* **CSS3 Moderno:** Estrategia **Mobile First**, layouts basados en **Flexbox** para componentes dinámicos y control del flujo de texto con propiedades avanzadas (`object-fit`, `letter-spacing`).
* **Componentes Nativos:** Implementación del logotipo personal utilizando únicamente **SVG y CSS nativo**, asegurando escalabilidad infinita y optimización de carga.
* **Git & GitHub:** Control de versiones con historial de commits descriptivos y despliegue automatizado.

## 📋 Lecciones Aprendidas & Desafíos Resueltos
* **Fidelidad de Diseño (Pixel Perfect):** Ajuste milimétrico de contenedores wrapper, paddings y espaciados (`gap`) para respetar la consistencia visual planteada en Figma.
* **Adaptabilidad de Texto:** Control del comportamiento del flujo de texto en pantallas pequeñas para evitar saltos de línea abruptos o desalineaciones respecto al prototipo original.
* **Enfoque Profesional Full Stack:** Optimización del contenido del perfil para reflejar de forma estratégica una sólida formación técnica en sistemas y desarrollo web.
